# Search Engine Shortcut Tags

Use shortcut tags to query specific search engines directly from the search bar without changing your default choice.

## Default Shortcuts

- `?g` - Google
- `?d` - DuckDuckGo
- `?b` - Brave
- `?bi` - Bing
- `?st` - Startpage
- `?s` - SearXNG
- `?e` - Ecosia
- `?k` - Kagi
- `?w` - Wikipedia
- `?y` - YouTube

## How It Works

Type a shortcut tag followed by a space and your search query in the search input box:

```text
?g how to build a web app
```

The system strips the tag before sending your search terms straight to that specific engine.

## Custom Engine Tags

When adding a custom search engine in Settings, assign any custom tag starting with `?` (such as `?pd` for Phind).
